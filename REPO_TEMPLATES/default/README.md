# Default Repository Template

This is a simple, language-agnostic starting point for small projects. It supports Python, C, and C++ by excluding common virtual environments, build outputs, temporary files, and logs from Git.

## Structure

```text
.
├── .gitignore          # Python, C/C++, temporary-file, and log exclusions
├── Docs/
│   ├── Plan/           # Goals, scope, milestones, and technical decisions
│   └── to-do/          # Actionable tasks and completion criteria
└── README.md           # Project overview and setup instructions
```

## Getting started

1. Copy this folder to create a new repository.
2. Replace this README with the project’s purpose, setup steps, and usage examples.
3. Add plans in `Docs/Plan/` and keep implementation tasks in `Docs/to-do/`.
